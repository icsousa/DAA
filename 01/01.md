# 01

- **NumPy**: Biblioteca fundamental para computação científica. Em Machine Learning, fornece estruturas de dados de alto desempenho para matrizes e arrays multidimensionais, que são a base matemática para a representação de dados numéricos e execução de operações algébricas pelos algoritmos.

- **Pandas**: Ferramenta de manipulação e análise de dados. É essencial na fase de pré-processamento em Machine Learning, permitindo carregar, limpar, transformar e explorar dados estruturados tabulares através dos seus DataFrames antes de os fornecer aos modelos.   

- **Matplotlib**: Biblioteca central para a criação de visualizações gráficas. É utilizada em Machine Learning para visualizar a distribuição dos dados de treino e traçar gráficos de avaliação do desempenho dos modelos, como curvas de erro ou dispersão de previsões.   

- **Seaborn**: Construída sobre o Matplotlib, foca-se na visualização de dados estatísticos de alto nível. O seu valor em Machine Learning reside na facilidade de gerar gráficos complexos, como matrizes de correlação (heatmaps), essenciais para a Análise Exploratória de Dados (EDA) e seleção de variáveis independentes.   

- **Scikit-learn**: A principal biblioteca de Machine Learning em Python. Contém as implementações dos próprios algoritmos preditivos (classificação, regressão, clustering), bem como módulos utilitários para cálculo de métricas de precisão, validação cruzada e separação de conjuntos de dados em treino/teste.   

- **JupyterLab**: Ambiente de desenvolvimento interativo. Permite combinar blocos de código Python, documentação formatada e resultados visuais gráficos numa única interface (notebooks), sendo a estrutura padrão para a experimentação, prototipagem iterativa e partilha de análises em projetos de Data Science.
